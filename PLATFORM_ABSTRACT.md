# Cybersecurity Log Analytics Platform - Abstract

This cybersecurity analytics platform is a batch-processing system that pre-processes and aggregates cybersecurity events for an anomaly detection model, which detects unusual computer behavior within a fictional enterprise network. The platform is demonstrated on a 14-day subset of the Los Alamos National Laboratory (LANL) dataset, covering four event types: authentication, process, network-flow, and DNS events.

The platform follows a lakehouse architecture and uses several microservices. A Data Producer Service (Python) replays the LANL subset as daily raw batches into the landing bucket of a MinIO object store. A Data Processing Service (Apache Spark) refines these batches through three Medallion layers, each a Delta Lake table in the MinIO object store. First, raw batches are ingested with schema validation into the Bronze layer, then cleaned and transformed into the Silver layer, and aggregated over a configurable 7-day rolling window into the Gold layer. A Data Delivery Service (Python) encrypts each Gold partition using Parquet modular encryption and writes it to a delivered bucket, from which the Mock Anomaly Detection Service consumes the preprocessed data and simulates retraining. All jobs for this pipeline are scheduled by an Airflow Orchestration Service with its own PostgreSQL metadata database. Additionally, every stage records lineage, schema versions, checksums, and delivery manifests in a separate PostgreSQL Governance Store. All components run as Docker containers in separate networks. GitHub will be used to version the source code, and GitHub Actions to provide a test and build pipeline.
